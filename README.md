# DP-700 Scenario Lab

A self-contained browser practice tool for the Microsoft Fabric Data Engineer Associate (DP-700) learning journey. It serves 120 original, scenario-based multiple-choice questions, gives immediate answer feedback, and links every explanation to the related Microsoft Learn documentation.

## Run locally

Open `index.html` in a modern browser, or run a static server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Content approach

This is deliberately **not** an exam dump and does not claim to reproduce real exam questions. Questions are original learning exercises built around Fabric concepts such as lakehouses, pipelines, Eventstreams, KQL databases, security, monitoring, and deployment pipelines. Microsoft Learn links are supplied for further study; always use the current [DP-700 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/dp-700) to plan preparation.
